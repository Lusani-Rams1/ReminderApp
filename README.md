# ReminderApp

ReminderApp is a simple academic productivity web app for students. It helps you stay organised with assignments, deadlines, notes, GPA tracking, and calendar integration in one place.

## Features

- **Dashboard** — quick overview of your study progress and upcoming work
- **Assignments / Tasks** — add, complete, delete, and filter academic tasks
- **Notes** — write and manage notes locally in the browser
- **GPA Calculator** — calculate your GPA from course marks and credits
- **Calendar** — view events by connecting Google Calendar
- **Responsive UI** — clean front-end pages built with HTML, CSS, and JavaScript

## Technologies Used

- HTML
- CSS
- JavaScript
- Local browser storage
- Google Calendar integration

## Project Structure

- `dashboard.html` — main dashboard
- `tasks.html` — assignments page
- `notes.html` — notes editor
- `gpa.html` — GPA calculator
- `calender.html` — calendar page
- `landing page.html` — marketing/intro page
- `CSS/` and `css/` — stylesheets
- `js/` — JavaScript functionality

## Getting Started

1. Clone the repository.
2. Open `dashboard.html` or `landing page.html` in your browser.
3. Navigate through the app using the top menu.

## Usage

- Add assignments from the Tasks page.
- Mark tasks as complete or delete them.
- Write notes and save them locally.
- Add courses and calculate GPA.
- Sign in with Google on the Calendar page to view events.
